# Larne

Larne is a local-first, visual scientific authoring tool that extends LaTeX
with modern workflows for figures, presentations, and computation.

## Status
Early prototype. Things will break.

## v0.1 Goals
- Edit LaTeX locally
- Open & save `.tex` files
- Monaco editor integration

## Non-goals (for now)
- Compilation
- PDF preview
- Collaboration
- AI
- Cloud sync
